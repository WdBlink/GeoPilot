# Knowledge and experience snapshot

This is a curated, publicly readable snapshot. It is not a complete transcript export or a replacement for the original hash-bound history directory.

| Record | Observation / purpose |
|---|---|
| [Tool knowledge](tool-knowledge.json) | Existing domain knowledge snapshot; facts and hypotheses retain their different status |
| [Shared intrinsics](shared-intrinsics.md) | A feedback-led positive development episode, with temporal provenance |
| [Program outcomes](program-outcomes.md) | Validly scored attempts and limits on what they support |
| [Measurements](../evidence/measurements.json) | Selected raw scalar values and original source identities |

Each experience separates the observation, interpretation, applicability and unresolved alternatives. A successful local change does not become a universal expert rule. Failed or mixed attempts are retained when they help interpret decisions; omitted raw logs are not evidence of an all-success campaign.

The current restricted compiler uses selected scored history; the outer Agent reads broader reports. Automatic distillation of every attempt and automatic retrieval on every optimization remain unimplemented. The tagged `v0.1.0` snapshot and subsequent dated knowledge updates contain development evidence only. Freeze later knowledge/selection rules before independent testing; do not feed test outcomes back and still call the same scenes held out.
