# Data access and evaluation scope

The study uses a local UseGeo-derived protocol. Start with the [dataset record](https://doi.org/10.1016/j.ophoto.2024.100070) and the acquisition/source information in the supplied input-contract code and source manifests. Obtain data from its original provider; this repository does not redistribute it.

The historical Dataset-1 comparison uses 224 Metashape-raster images. The separate S-U/F-U comparison uses 224 publisher-undistorted images. Matching filenames do not make these pixel sets interchangeable. The three locally organized scenes contain 224, 327 and 277 matched image/orientation records, respectively.

Full and refined LiDAR sets have different directional evaluation roles. Do not expose evaluation references as reconstruction inputs or fit the output to them under the reported protocol. All three registered scenes participated in development; they are not untouched independent tests.

The public measurements are selected scalar fields, not a geometry data release or a complete rerunnable archive. Source SHA256 identities refer to the original local score artifacts. Full reconstruction/evaluation also requires the frozen input/bundle manifests, actual numerical runtime, and raw data described by the source entries. The current release does not regenerate all historical binding identities from an arbitrary fresh download.
