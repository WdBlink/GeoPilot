# Contributing

Open an issue describing the affected command, environment, expected behavior and actual result. Use synthetic or redistributable inputs; remove credentials and personal paths.

Keep changes focused and run the quick artifact check and relevant existing tests. Describe whether a patch changes numerical behavior, permissions, candidate space, evaluation semantics or only documentation. A changed method/protocol needs a new identity; do not overwrite historical results or silently reinterpret them as measurements of the new version.

Experience contributions should distinguish an observation from an explanation, include source/version and applicability, and preserve unsuccessful cases relevant to the conclusion. A passing unit test is not evidence of improved reconstruction.

By submitting original contributions, you agree to their distribution under this repository's MIT license. Preserve third-party notices. Please keep discussions respectful and focused on evidence.
